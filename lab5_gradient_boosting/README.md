# ЛР-5. Градиентный бустинг

Ноутбук: `lab5_gradient_boosting.ipynb`. Своя реализация: `../src/boosting.py` —
последовательное добавление деревьев регрессии на антиградиент функции потерь:
для классификации логистическая потеря с шагом Ньютона (постоянная кривизна
0.25), для регрессии — квадратичная потеря. Поддерживается `subsample`.

## Задачи

Классификация направления по акциям MOEX (TQBR), регрессия доходности
облигаций MOEX (TQCB). Данные и разбиение — как в ЛР 1–4.

## Ход работы

1. Бейзлайн sklearn: `GradientBoostingClassifier` / `GradientBoostingRegressor`
   (200 итераций, lr 0.1, глубина 3).
2. Свой бустинг с теми же параметрами (лист ≥ 10 наблюдений).
3. Гипотезы:
   - сетка `n_estimators` (100 / 300) × `learning_rate` (0.05 / 0.1 / 0.3);
   - глубина базового дерева 2 / 3 / 5;
   - стохастический бустинг: `subsample` 0.5 / 0.8 / 1.0;
   - кривая RMSE по числу итераций (10…400).

## Выводы

- Свой бустинг по классификации почти на уровне sklearn (0.538 против 0.543),
  в регрессии обходит его (RMSE 0.915 против 1.019) — при том же числе
  итераций, но с листом ≥ 10 наблюдений.
- Шаг и число итераций нужно согласовывать: лучший RMSE 0.9066 при lr 0.1,
  n = 100; lr 0.3 деградирует до 0.955–0.982.
- Глубина 2–3 — оптимум; на 5 падает и accuracy (0.523), и RMSE (0.923).
- Подвыборка на итерацию почти ничего не даёт (0.9139 против 0.9149).
- Классификация: бустинг — лучший результат среди всех ЛР (accuracy 0.543),
  но потолок ≈ 0.54 не пробит.
- Регрессия: бустинг (0.915) не обгоняет ни ridge (0.905), ни наивный прогноз
  (0.888 из ЛР-2) — доходность облигаций почти не предсказуема.
