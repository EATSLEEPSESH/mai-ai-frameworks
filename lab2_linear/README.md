# ЛР-2. Линейная и логистическая регрессия

Ноутбук: `lab2_linear.ipynb`. Своя реализация: `../src/linear.py`
(логрегрессия и линейная регрессия полным градиентным спуском, ridge в замкнутой форме).

## Задачи

Классификация направления по акциям MOEX (TQBR) и регрессия доходности
облигаций MOEX (TQCB). Разбиение хронологическое, масштабирование — по трейну.

## Ход работы

1. Бейзлайн sklearn: `LogisticRegression`, `Ridge`.
2. Наивный прогноз для регрессии «завтра = сегодня» — нижняя планка, без неё
   высокий R² вводит в заблуждение.
3. Свои реализации: логрегрессия (логлосс + L2, GD), ridge в замкнутой форме,
   линейная регрессия GD.
4. Гипотезы:
   - сила L2 (0.01…100);
   - порог классификации (0.45…0.55);
   - урезанный набор признаков без длинных лагов.

## Выводы

- Линейные модели воспроизводятся своими реализациями; замкнутая формула ridge
  устойчивее градиентного спуска при фиксированном шаге.
- Регуляризация почти не влияет: признаки слабые, переобучения нет.
  При λ = 100 RMSE деградирует (0.933).
- Порог — единственный работающий рычаг: при 0.45 recall 0.79 и F1 0.58,
  но accuracy падает до 0.469. Одновременно хороших accuracy и F1 нет.
- В регрессии наивный прогноз лучше моделей (RMSE 0.888 против 0.905):
  высокий R² — инерция доходности, а не предсказание. Планка для нелинейных
  моделей: RMSE < 0.888, accuracy > 0.51.
