# ИИ-фреймворки — лабораторные работы

Пять лабораторных и итоговое сравнение алгоритмов на двух датасетах с Московской
биржи (MOEX ISS API):

| Задача | Датасет | Что предсказываем |
|---|---|---|
| Классификация | **MOEX Equity Panel** — дневные торги акциями, режим TQBR | вырастет ли цена закрытия на следующем торговом дне |
| Регрессия | **MOEX Bonds Panel** — дневные торги облигациями, режим TQCB | доходность к погашению (`YIELDCLOSE`) на следующем торговом дне, % |

Зачем это нужно: направление дневного движения акции — для коротких торговых
стратегий и алертов риска, доходность облигации — для оценки процентного риска
портфеля и переоценки бумаг. Обе задачи — табличные временные ряды, на них
и проверяю модели от KNN до градиентного бустинга.

Период: 2021-01-01 … 2026-11-25. Кандидаты — топ-80 бумаг по обороту; после
фильтра по ликвидности остаётся 48 акций (59,6 тыс. наблюдений) и 38 выпусков
облигаций (18,9 тыс. наблюдений). Разбиение строго по времени: обучение — до
2025-01-01 (акции) / до 2025-10-01 (облигации), тест — более поздний период.
Перемешивать нельзя, иначе утечка из будущего.

гиперпараметров/признаков), итоговые метрики и выводы отдельно для
классификации и для регрессии.

## Короткий итог

| Задача | Лучший результат | Комментарий |
|---|---|---|
| Классификация | sklearn GBM: accuracy 0.5433, ROC-AUC 0.5367 | константа «вниз» даёт 0.5367 — сигнал слабый |
| Регрессия | наивный прогноз: RMSE 0.8877 | лучшая модель (ridge) — 0.9047; высокий R² — инерция |

Дневное направление цены акции предсказуемо плохо, accuracy около 50 % —
это ожидаемый результат, а не ошибка модели. В регрессии доходность облигации
почти не меняется день ото дня, поэтому «завтра = сегодня» обгоняет все модели.

## Данные

Два варианта.

**1. Готовые признаки уже в репозитории** — `data/processed/*.csv` (27 МБ, выгрузка
на 23.11.2026). Клонируешь и сразу запускаешь ноутбуки, сеть не нужна.

**2. Пересобрать с нуля из ISS** (альтернатива, если нужны свежие данные):

```bash
python scripts/fetch_moex.py        # data/raw/{shares,bonds}.csv + справочники
python scripts/build_features.py    # data/processed/*_features.csv
```

`scripts/russian_trusted_ca.pem` — корневой сертификат Russian Trusted (Минцифры),
им подписана цепочка `iss.moex.com`; он передаётся в `urllib` явно, проверка TLS
не отключается.

## Запуск

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/Scripts/python.exe -r requirements.txt
# данные уже в репозитории, пересобирать не нужно; если всё же надо:
# python scripts/fetch_moex.py && python scripts/build_features.py
.venv/Scripts/python.exe -m jupyter nbconvert --to notebook --execute --inplace lab1_knn/lab1_knn.ipynb
# и так далее по lab2…lab6 — lab6 читает results/results.jsonl, поэтому запускается последним
```

Ноутбуки находят корень репозитория по маркеру `src/`, поэтому запускаются
и из своей папки, и из корня.

## Метрики

Классификация: accuracy, precision, recall, F1, ROC-AUC (свои реализации —
`src/metrics.py`). Регрессия: RMSE, MAE, R². Метрики всех лабораторных
складываются в `results/results.jsonl` (в git не входит) и собираются в ЛР-6.
