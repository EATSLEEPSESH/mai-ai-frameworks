# Сводное сравнение алгоритмов

Ноутбук: `lab6_comparison.ipynb`. Читает `../results/results.jsonl` (метрики
всех лабораторных, пишутся функцией `save_result`) и строит сводные таблицы
и графики по двум задачам.

## Задачи

Сопоставить KNN, линейные модели, дерево, случайный лес и градиентный бустинг
(свои реализации и бейзлайны sklearn) на одних и тех же данных, объяснить
разброс метрик и сформулировать общий вывод.

## Ход работы

1. Загрузка метрик из `results.jsonl`, дедупликация по (lab, task, model).
2. Таблица классификации по ROC-AUC, таблица регрессии по RMSE.
3. Тривиальный бейзлайн: константный прогноз «вниз» (доля падений в тесте
   0.5367) — нижняя планка accuracy.
4. Графики: ROC-AUC и accuracy − 0.5; RMSE и R².
5. Итоговые выводы и оговорки.

## Выводы

- Классификация: лучшее — бустинг (accuracy 0.543, AUC 0.537), но константа
  «вниз» даёт 0.5367 accuracy — преимущество модели всего 0.7 п.п.
  Линейная модель по AUC хуже монетки (0.492): сигнал нелинейный и очень слабый.
- Регрессия: наивный прогноз «завтра = сегодня» обгоняет все модели
  (RMSE 0.888); среди моделей лучшая — ridge (0.905). Высокий R² — инерция
  уровня доходности, а не предсказание.
- Свои реализации совпадают со sklearn в контрольных точках (дерево, KNN,
  ridge), различия у ансамблей объясняются гиперпараметрами.
- Главное: на этом наборе признаков признаки важнее алгоритма —
  разброс между семействами (3.5 п.п. accuracy, 4.5 п.п. AUC) меньше,
  чем вклад выбора постановки задачи.
- Ограничение: гиперпараметры подбирались по тесту, строгий эксперимент
  требует отдельного валидационного периода.
